<Code src="sudo nginx -t" language="sh" />

##  Avahi

<Code src="sudo nano /etc/avahi/avahi-daemon.conf" language="sh" />

change this line to `wlo1` in the avahi daemon config

<Code src="allow-interfaces=wlo1" language="ini" />

### Start

<CodeLine language="sh" src="start_local_server" />

<Code src="sudo systemctl restart avahi-daemon" language="sh" />

<Code src="avahi-publish -a -R grafana.local 192.168.178.103" language="sh" />

### Test

<Code src="avahi-resolve -n grafana.local" language="sh" />
