## Android

For the android user i did make a tutorial for Virtual Master and VPhoneOS, but it is not that hard to do it without one. First either install **Virtual Master** or **VPhoneOS** from the google play store or any other Virtual Maschine to get a running Version of Android 5. This is required to play the Game. Inside there, create a android 5 virtual machine and install the files like show in the [video](https://www.youtube.com/watch?v=A4MXIzqetrs) **(after i open the MSI App player on pc, this is basicly an android virtual machine)**.
